# 🚀 Belajar Go: Variabel & Tipe Data Dasar

Halo! Ini project pertamaku nyobain Go (a.k.a Golang).  
Masih basic banget, isinya latihan pake variabel, tipe data, sama format angka biar tampilannya kece kayak di dompet 😌💸

## 🧠 Apa yang Dipelajari?
- Cara bikin variabel (pakai `var` & `:=`)
- Tipe data dasar: `string`, `int`, `float64`
- Cara print ke terminal
- Format angka jadi Rp3.500.000 (biar nggak 3.5e+06 😵)

## 🛠️ Yang Dibutuhin
Satu dependensi doang:
```bash
go get golang.org/x/text
```

# 📁 Struktur
```bash
.
├── go.mod
└── tipedata.go
```

# ▶️ Cara Running
```bash

go run tipedata.go
```

# 🖥️ Output-nya Kira-kira Gini:
```bash
Nama: Freya
Umur: 33
Kota: Surabaya
Gaji: Rp3.500.000
```
